> Live Website: [https://moshaban.me](https://moshaban.me)

This branch (`main`) serves the live, production-compiled version of the **ALIA Strategic Consulting Smart Digital Business Card & Executive Profile** via GitHub Pages.

---

## 🚀 Features
- **Executive Smart Card**: Official credentials for Mohamed Shaban, Strategic Consultant & GTM Architect.
- **ALIA 5 Revenue Engines Architecture**: Interactive breakdown of Demand, Conversion, Expansion, Data Intelligence, and AI Transformation.
- **Dual Dynamic QR Codes**: URL web profile link & standard vCard 3.0 contact pass.
- **Instant Contact Save**: Export direct `.vcf` vCard to mobile devices.
- **Portfolio PDF Access**: Direct integrated download for the official ALIA Growth & Revenue Portfolio (~25MB).
- **Arabic / English Bilingual Support**: Seamless bilingual toggle.
