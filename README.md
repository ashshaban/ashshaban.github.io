# ALIA Strategic Consulting — Smart Digital Business Card

> Executive Profile & Interactive Revenue Architecture for **ALIA Strategic Consulting** (An Amer Vision Group Company)
> Live Website: [https://moshaban.me](https://moshaban.me)

---

## 🌟 Overview
Smart digital business card and executive profile platform featuring:
- **Interactive ALIA 5 Revenue Engines Architecture** (Demand, Conversion, Expansion, Data Intelligence, AI Transformation).
- **Dynamic Dual QR Code Generator**: Direct Web Profile URL & Standard vCard 3.0 Contact Pass.
- **Instant vCard .vcf Contact Card Export** (One-click save to phone contacts with full corporate credentials).
- **Instant Portfolio PDF Access**: Direct integrated download for the official ALIA Growth & Revenue Portfolio (~25MB).
- **Arabic / English Bilingual Switch**: Full bilingual support with automated typography and layout flow.
- **One-Touch Communication Actions**: Direct WhatsApp, Phone Call, Email, LinkedIn, and HQ Navigation.

## 🛠 Tech Stack
- **Framework**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS v4 + Motion
- **Icons**: Lucide React
- **QR Generation**: QRCode.react
- **Hosting**: GitHub Pages with Custom Domain (`moshaban.me`)

## 🚀 Local Development
```bash
# 1. Install dependencies
npm install

# 2. Start local dev server
npm run dev

# 3. Build for production
npm run build
```
